# Lab-Grown Diamond 45s 3D Short (GitHub Actions Parallel Blender Render)

Renders your 45-second Zack-style 3D Short starring your 25-year-old Indian man across **12 parallel GitHub Actions runners**—no Kaggle editor, no browser crashes, and works cleanly from mobile.

## Quick Setup (Works on Mobile)
1. Create a new GitHub repository (public repos get unlimited free GitHub Actions minutes).
2. Unzip `lab-diamond-gh-actions.zip` and upload `.github/workflows/render-diamond-short.yml` and the `scripts/` folder to the repo.
3. Open the **Actions** tab → select **Render Lab-Grown Diamond 45s 3D Short** → tap **Run workflow**.
4. Choose `test_sheet` (~5 min preview of all 12 shots) or `full_mp4` (complete 45s voiced MP4 with `@always_animate` watermarks and bold captions).
5. When finished, scroll to **Artifacts** on the completed workflow page and download **`lab-diamond-short-output`**.
